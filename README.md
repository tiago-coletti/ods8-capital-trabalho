# ODS 8: Capital vs. Trabalho no Brasil (`r > g`)

Plataforma web analítica que consome, trata e visualiza dados em séries temporais para comparar a evolução do rendimento do capital (Taxa Selic/BCB) e do crescimento econômico/trabalho (PIB/Ipeadata) no Brasil.

O projeto fundamenta-se nos diagnósticos de Thomas Piketty, Celso Furtado e outros para evidenciar visualmente as barreiras estruturais para o alcance da **Meta 8.5 do ODS 8 da ONU**.

## Funcionalidades Principais
- **Painel Gráfico Interativo:** Sobreposição das variáveis $r$ (juros) e $g$ (crescimento/trabalho).
- **Acervo Teórico:** Resumos e links para obras clássicas e dados oficiais de acesso aberto.
- **Transparência de Dados:** Detalhamento do consumo das APIs do Banco Central do Brasil e IPEA.

## Fontes e Referências
- Banco Central do Brasil (BCB)
- Instituto de Pesquisa Econômica Aplicada (Ipea)
- GT Agenda 2030 (ODS 8)
